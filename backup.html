TGM — Backup e Restauração

Faz backup do status das tarefas (Pendente/Em Andamento/Concluída) para um arquivo no seu computador, e restaura a partir de um arquivo salvo.
O código do site (index.html, gráficos, tarefas cadastradas etc.) já fica salvo automaticamente no GitHub a cada atualização — não precisa de backup à parte. O que não fica salvo em lugar nenhum além do banco de dados é o status marcado em cada tarefa, porque qualquer visitante pode alterá-lo a qualquer momento. É só isso que este backup guarda.

Baixar backup

Baixa um arquivo .json com o status atual de todas as tarefas.

Restaurar backup

Escolha um arquivo .json baixado anteriormente para restaurar o status das tarefas. Isso sobrescreve o status atual — visível para todos os visitantes do site.
TGM — ferramenta de backup do status das tarefas. Dados salvos no Supabase (tabela tgm_task_status).
